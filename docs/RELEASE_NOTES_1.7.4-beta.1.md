# Automatic filename date detection ? testing prerelease

Recognizes the configured Daily Notes filename format and the same 12 common numeric and English month-name formats as Morning Pages in any eligible folder. Ambiguous dates are skipped; undated filenames retain creation-time grouping. Folder exclusions remain enforced.

## Important limitation
Use a separate test vault. Existing creation-date summaries are preserved but can become stale or be recalculated from a smaller source set after regrouping. Historical migration and accurate record provenance are unfinished. This prerelease is not recommended for an existing production mood history. It does not replace the stable release.

Full functional and mobile-runtime suites and privacy audit passed locally. Native installation and historical migration have not been verified. No claim is made that every possible date notation is recognized.
