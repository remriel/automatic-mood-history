## Ten-point scores

New local and Groq results score mood, energy, connection, and intensity from 1 to 10. The dashboard and refreshed monthly exports display older scores as 1, 3, 6, 8, or 10. Saved results and monthly recovery data retain their original values. Older daily notes retain their original scale.

## Groq and analysis controls

- Removed the full-history retry buttons from the dashboard and Settings. **Reanalyze all notes with Groq** is available from the command palette and requires a key.
- Deferred legacy retries keep the saved result while waiting for Groq.
- Settings now describes the opt-in folder default. Empty scans explain how to select eligible folders.

Update all devices that share this plugin's data before syncing new scores. Older versions support a maximum of 5.
