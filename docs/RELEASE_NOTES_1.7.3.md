# Automatic Mood History 1.7.3 — Range-aware summaries

The trend window now controls the summary tiles above the chart as well as the plotted dates.

- **Compare the selected period:** average-score tiles update to match the selected 7-, 14-, 30-, 60-, 90-, 365-day, or all-history range.
- **See how many days are represented:** the Days scored tile follows the same selected range.
- **Keep history intact:** history continues to show all records regardless of the selected trend window. Saved records and analysis settings are unchanged.

## Install or update

Use [BRAT](https://github.com/TfTHacker/obsidian42-brat) with [the plugin repository](https://github.com/remriel/automatic-mood-history), or copy `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/automatic-mood-history/` in your vault. The optional `moodring-model.bin` goes in the same folder. Restart Obsidian and enable the plugin.

Scores are text inferences, not medical assessments.
