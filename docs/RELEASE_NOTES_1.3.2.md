# Automatic Mood History 1.3.2

Preserve emotional content that was discarded when writing was analytical, addressed someone else, or arrived in an imperfect provider response.

- Keep source-grounded textual charge from commentary, clippings and second-person passages. Textual evidence supports intensity only and is explicitly labeled; personal mood, energy and connection require their own evidence.
- Repair observations/limitations placed outside `insights` only when unambiguous. Exact source quotations, bounds, diagnostic-label exclusions and attribution checks still apply.
- Leave a contradictory numeric axis unscored, explaining the omission while retaining other valid evidence. No replacement score is invented.
- Review every first empty assessment once, without requiring a matching local emotion word. Genuinely neutral text can still abstain; omitted recognizable personal evidence remains pending.
- Keep validated emotion labels even if the redundant top-level tag list omits them. Labels remain limited to six.
- Use medium reasoning effort for GPT-OSS 20B/120B with the existing selected model, completion limits and cancellation/rate-limit behavior.
- Separate textual and personal intensity in historical numerical comparisons.

Validation covers synthetic regression cases, full functional tests, responsive evidence rendering, persistence and privacy checks. Local validation also used three user-reported dates with the already enabled provider; no private note text or provider output is included in this repository. These checks establish engineering behavior, not psychological accuracy.

Existing remote results are preserved until explicit reanalysis. Use **Analyze the active note** to refresh a selected creation-date group, or **Retry all with Groq** for all eligible groups. Existing folder scope and provider consent still apply.
