# Automatic Mood History 1.7.5

The trend range selector now includes **Custom**. Choose inclusive start and end dates and click **Apply range**. The chart, Days scored count and average tiles use the chosen dates. Reversed dates show a helpful message, and ranges without scored days show an empty state. Select any preset to return to a standard range.

Range selection is temporary, like the existing presets. Reopening the dashboard restores its default 14 days. Saved records and full history remain intact.
