# Automatic Mood History 1.7.1 — Clearer trends

The trend view gives each metric a solid, clearly labeled line and a cleaner presentation.

- **Follow each score:** mood, energy, connection, and intensity use solid lines with matching legend controls above the chart.
- **Find a day quickly:** the selected point is highlighted in each plot, and its value appears beside the metric name. The slider and date readout remain available for keyboard and touch.
- **Read dense histories:** smaller markers reduce clutter while keeping all recorded points and their actual calendar spacing.
- **See missing values honestly:** a missing score on a recorded day breaks that metric's line. Lines between recorded scores do not estimate unrecorded days.

Saved scores, analysis settings, and series visibility are preserved. Time-window and selected-day choices remain temporary. Scores are text inferences, not medical assessments.

## Install or update

Use [BRAT](https://github.com/TfTHacker/obsidian42-brat) with `https://github.com/remriel/automatic-mood-history`, or copy `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/automatic-mood-history/`. The optional `moodring-model.bin` goes in the same folder. Restart Obsidian and enable the plugin.
