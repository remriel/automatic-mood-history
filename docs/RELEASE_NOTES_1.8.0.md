# Compact history and imported note dates

Choose monthly Markdown output to keep one readable file per month, including full saved-record recovery data. Dashboard-only output is also available, and daily output remains the compatibility default. Daily details now expose confidence, signals and original source-note links directly in the dashboard.

Imported filenames such as `2024-03-04 (2).md` and `Notes — March 4, 2024.md` now group by their original dates. Choose month–day–year, day–month–year, or skip for ambiguous numeric dates. Two distinct dates in one title remain ambiguous. Undated notes retain creation-date fallback.

Changing output preserves existing files. Monthly exports do not rerun analysis and never overwrite edited exports. Back up plugin data and monthly exports, verify saved records, and preserve older or edited entries before archiving daily files. Native Bases requires daily entries. Monthly recovery data is portable but is not automatically imported on restore. Corrected date groups need Analyze changed; existing scores are not copied into newly split groups.

Validation covers export round trips, separate history identities, interruption recovery, manual-edit protection, dashboard-only persistence, imported date formats, numeric conventions, source scope, cancellation, and desktop/mobile layouts.
