# Automatic Mood History 2.0.0

This release makes the dashboard's cards easier to read, with desktop use first.

- Summary cards have more breathing room for their labels and values. A wide desktop pane keeps five equal cards across the full row; narrower panes and larger text reflow them into balanced rows.
- Recorded-day cards and the date selector also make room for larger text so labels and scores remain readable.
- Existing history, analysis, settings, and selected-range calculations remain unchanged.

## Install or update

Update with [BRAT](https://github.com/TfTHacker/obsidian42-brat) using the [plugin repository](https://github.com/remriel/automatic-mood-history), or copy `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/automatic-mood-history/` in your vault. Restart Obsidian and enable the plugin.
