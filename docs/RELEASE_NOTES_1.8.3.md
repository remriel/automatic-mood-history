# Pastel composition chart and monthly history by default

Composition over time now matches the Morning Pages Analytics chart style: a compact color key, calendar-aligned stacked columns, 0/50/100% guides, and daily or wider calendar periods as the selected range grows. It uses up to ten most common emotions across all saved scored history, including older records, so categories remain consistent when changing ranges. Each visible emotion has its own pastel color; anxiety, frustration and sadness have distinct hues. Other emotion labels are excluded from each period's denominator, and **Period details** gives exact counts and percentages.

Monthly Markdown output is now the default when no output choice has been saved. Existing saved daily or dashboard-only choices remain unchanged; choose Monthly in settings if desired. A legacy unfinished write retains its original output mode for safe recovery. Use **Export months** to create monthly notes for existing history. No daily note is removed automatically.

Verification covers color separation and matching legends in light and dark themes, aligned percentage-based columns, date ranges, global top-ten selection, mobile layouts, saved preferences, and legacy pending-write recovery. This update does not itself trigger analysis.
