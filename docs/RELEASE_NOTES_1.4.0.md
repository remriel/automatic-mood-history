# Automatic Mood History 1.4.0

Complete eligible source accounting replaces prefix truncation. Long dates use deterministic passage chunks, explicit passage acknowledgments, source/analysis fingerprints and durable resumable progress within the existing character budget. Older remote history is marked stale or coverage unknown and can be repaired through a selectable preview; upgrades do not silently backfill the vault.

All four dimensions receive explicit supported, unsupported or ambiguous assessments. Invalid anchors and direction conflicts remain unresolved, receive one targeted review and preserve valid staged dimensions and the previous successful entry. Provider evidence records quotation provenance, personal/textual basis, explicit/inferred meaning, temporal context and support. Aggregation balances distinct concepts and opposing directions independently of chunk count and bounded displayed evidence. Local inference remains conservative English-only.

Dashboard averages, provenance, emotion summaries and charts retain independent connection, energy and intensity results; missing axes make line gaps. Processing and assessment status are separate, including explicit minimum-character exclusions and unknown historical coverage.

Existing nullable score properties, legacy identities, edited generated notes, provider consent, source exclusions, serialized requests and prepared-write recovery remain compatible. Pending metadata and retained quotations are sensitive local derived data; see PRIVACY.md. No clinical accuracy claim is made.

Validation evidence is recorded in docs/COVERAGE_DESIGN.md and the coverage evaluation/performance reports. Install main.js, manifest.json and styles.css together from this release.
