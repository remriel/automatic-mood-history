# Automatic Mood History 1.7.7

Composition over time now displays only the seven most common emotions in the selected date range. There is no combined category. Each period?s percentages are calculated from the displayed emotions; a period with none of those seven appears blank. Period details report the same counts and percentages.

The chart recalculates its top seven when you change the selected preset or custom range. This display change uses existing records; no reanalysis is needed. Common Emotions continues to follow the selected date range.

## Seven-day moving averages

Each trend plot can display a seven-calendar-day trailing moving average as a dashed line with hollow diamond markers. The average uses the current date and six preceding calendar days within the selected range, ignores missing scores, and needs at least two recorded scores. The selected-day readout includes the average. Use the **7-day moving average** button to show or hide it; it is shown by default.

The range and toggle are view controls. They do not alter saved scores, and reanalysis is not required.
