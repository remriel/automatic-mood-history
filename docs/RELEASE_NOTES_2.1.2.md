# Automatic Mood History 2.1.2

- **Clearer monthly exports:** Explain that export writes existing analyzed records, indicate when an export is running, and report the months written.
- **Edited months stay protected:** Continue exporting other months when one monthly note has been edited, while preserving the edited note and explaining how to refresh it.
- **No-history guidance:** Direct users to analyze changed notes when there are no saved records to export.

## Install or update

Update with [BRAT](https://github.com/TfTHacker/obsidian42-brat) using the [plugin repository](https://github.com/remriel/automatic-mood-history), or copy main.js, manifest.json, and styles.css into .obsidian/plugins/automatic-mood-history/ in your vault. Restart Obsidian and enable the plugin.
