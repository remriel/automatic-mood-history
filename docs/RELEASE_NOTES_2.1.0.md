# Automatic Mood History 2.1.0

- **See the selected day's emotions:** Explore a Recorded Day now shows the emotion labels saved for that particular date. They update when you choose another date or select a point on the chart. If a day has no recorded emotions, the panel says so.
- **More compact desktop cards:** Recorded-day cards are approximately 30% smaller on a wide desktop pane, with readable labels and responsive layouts for narrower panes and larger text.
- The display uses existing saved records; it does not reanalyze notes or change scores.

## Install or update

Update with [BRAT](https://github.com/TfTHacker/obsidian42-brat) using the [plugin repository](https://github.com/remriel/automatic-mood-history), or copy `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/automatic-mood-history/` in your vault. Restart Obsidian and enable the plugin.
