# Automatic Mood History 2.1.1

- **Tighter Explore a Recorded Day spacing:** Reduced outer and inner padding, header bottom spacing, and card/emotion box vertical gaps so the explorer sits more compactly beneath the trend chart.
- **UI polish:** Refined the explorer heading scale, left accent bar alignment, subtitle contrast, and date picker hover feedback while preserving desktop card readability and 44px mobile touch targets.

## Install or update

Update with [BRAT](https://github.com/TfTHacker/obsidian42-brat) using the [plugin repository](https://github.com/remriel/automatic-mood-history), or copy `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/automatic-mood-history/` in your vault. Restart Obsidian and enable the plugin.
