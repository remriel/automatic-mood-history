# Automatic Mood History 1.7.8

The trend chart's moving-average window now adapts to the selected date range. It uses one fifth of the range, rounded to whole calendar days with a two-day minimum. For example, 7 days uses a 2-day average and 30 days uses a 6-day average. All uses the full span of recorded dates; Custom uses the inclusive dates you select. The button and selected-day readout show the current window.

Averages use only available scores inside the selected range and require at least two scores. Dashed lines and hollow diamonds can be toggled as before.

Composition over time now assigns a consistent color to each emotion as rankings and ranges change. Chart segments and legend swatches use matching colors, even when a theme broadly styles SVG shapes. The chart and legend also have a refreshed presentation.

These are display changes: existing records and scores are unchanged, and no reanalysis is needed.
