# Streamlined dashboard

The summary cards and dashboard button rows are centered, including when they wrap. Toolbar, range, custom-range and series buttons use the same compact sizing, with larger touch targets on phones. Narrow cards keep their labels readable.

Moving-average controls, explanations, dashed lines, markers and day readouts have been removed. The four recorded-score trends, range controls, selected-day details and summary averages remain unchanged. This is a display update and does not alter saved records.
