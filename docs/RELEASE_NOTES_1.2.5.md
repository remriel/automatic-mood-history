## Automatic Mood History 1.2.5

The trend chart now plots intensity alongside mood, energy, and connection on the same 1–5 scale. Intensity uses a purple trace with a distinct dash-dot pattern, a legend entry, and date/score tooltips.

The chart reads existing saved intensity scores, so this update requires no new analysis. Missing scores are omitted. Light and dark themes, narrow panes, and enlarged text remain supported.

Groq-only analysis and legacy-date recovery from 1.2.4 remain included. Release assets include GitHub build provenance attestations.
