# Automatic Mood History 1.7.2 — More trend ranges

- Explore your trend over **7 days**, **14 days**, or **60 days**, alongside the existing 30-day, 90-day, 1-year, and all-history options.
- The trend opens at **14 days** by default. Each window includes the latest scored day and counts back from that date.
- Range choices affect the chart only. Saved scores, summary cards, history, and analysis settings are unchanged.

## Install or update

Use [BRAT](https://github.com/TfTHacker/obsidian42-brat) with `https://github.com/remriel/automatic-mood-history`, or copy `main.js`, `manifest.json`, and `styles.css` into `.obsidian/plugins/automatic-mood-history/`. The optional `moodring-model.bin` goes in the same folder. Restart Obsidian and enable the plugin.
