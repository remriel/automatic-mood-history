## Folder scope

- **Include specific folders** is the default. Add one vault-relative folder per line. A blank list pauses note analysis.
- **Scan all except excluded folders** is a separate option. Leave its exclusion list blank to scan every eligible folder. The two lists are saved independently.
- Subfolders follow their parent folder rules. Use / for root-level notes. Generated history and trash stay outside analysis.
- Upgrading from whole-vault scanning requires choosing the scan-all mode again. If an old inclusion overlaps an exclusion, review that part of the scope before adding it back. Saved history is preserved.
